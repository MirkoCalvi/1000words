# 1000 Words — Spanish Vocabulary Trainer

Offline, no-login Android app for learning the 1000 most common Spanish words
through flashcards and multiple-choice quizzes. No account needed — just build
from source or install the APK.

See [CLAUDE.md](CLAUDE.md) for full project context and design decisions.

## Build & run

Requires JDK 17 and the Android SDK (Android Studio handles both).

```bash
git clone <this repo>
cd 1000words
./gradlew assembleDebug
```

Or open the project folder in Android Studio and press Run.

The debug APK lands at `app/build/outputs/apk/debug/app-debug.apk` — install it
with `adb install app-debug.apk` or by opening it on your device.

## Status

- App shell, Room database, and all 6 screens (Home, Flashcards, Quiz, Conjugate
  Verbs, Complete the Sentence, Thematic Learning) are implemented per CLAUDE.md.
- `app/src/main/assets/words.json` + `conjugations.json` ship the full 1000-word
  dataset (~530 verbs with present/preterite conjugations, ~470 nouns across 20
  thematic categories), generated by `tools/generate_words.py`.
- Manually tested on a real device — all 6 flows confirmed working.
