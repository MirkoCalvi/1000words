# CLAUDE.md — Spanish Vocabulary Trainer (Android)

This file gives Claude (or any contributor) full context on the project so work can
continue consistently across sessions. Keep this file updated as decisions change.

## 1. Project Summary

A simple, offline, no-login Android app that helps the user learn the 1000 most
common Spanish words (nouns and verbs) through flashcards, multiple-choice quizzes,
verb conjugation drills, sentence completion, and themed daily vocabulary. The app
is intended to be published on a public GitHub repo so anyone can clone, build, and
install it.

**Guiding principle: keep it as simple as possible** within that feature set — avoid
adding further screens or dependencies beyond what's described here for the core
loop of "see word → recall/answer → track progress → maintain a daily streak."

## 2. Non-Goals (explicitly out of scope)

- No login, accounts, or auth of any kind
- No backend server or cloud sync — 100% local/offline
- No push notifications (v1)
- No settings screen, no theming toggle (v1)
- No monetization, ads, or analytics/tracking SDKs
- No per-word "3 strikes" mechanic — the only streak tracked is the **daily
  streak** (consecutive calendar days the user completed at least one session)

## 3. Tech Stack

- **Language**: Kotlin
- **UI**: Jetpack Compose
- **Database**: Room (local SQLite), no network libraries needed
- **Async**: Kotlin Coroutines + Flow
- **DI**: none required at this scale — keep it simple, use manual constructor
  injection or a single `AppContainer` object instead of Hilt
- **Min SDK**: 24 (Android 7.0), covers the vast majority of devices
- **Build system**: Gradle (Kotlin DSL, `build.gradle.kts`)
- **Dev environment**: Ubuntu, Android Studio (installed via `snap install
  android-studio --classic`)

## 4. App Structure

1. **Home Screen**
   - Shows current daily streak (e.g. "🔥 5 day streak")
   - Shows overall progress (e.g. "230 / 1000 words mastered")
   - Buttons: "Practice Flashcards", "Take Quiz", "Conjugate Verbs",
     "Complete the Sentence", "Thematic Learning"
2. **Flashcard Session Screen**
   - Shows Spanish word (and part of speech tag: noun/verb)
   - Tap to reveal English translation + example sentence
   - Two buttons after reveal: "Got it" / "Still learning"
   - Session ends after a fixed batch (e.g. 20 words), returns to Home
3. **Quiz Session Screen**
   - Shows Spanish word, 4 multiple-choice English translations
     (3 distractors pulled from words of the same part of speech)
   - Immediate feedback (correct/incorrect), then next question
   - Session ends after a fixed batch (e.g. 20 words), returns to Home
4. **Conjugate Verbs Screen**
   - Shows a verb infinitive + person (yo/tú/él/nosotros/vosotros/ellos) + tense
     (present or preterite), 4 multiple-choice conjugated forms (correct + 3 other
     forms of the same verb/tense)
   - Immediate feedback, then next question; batch of 20, returns to Home
   - Backed by `assets/conjugations.json` (see §5) — only verbs have conjugations
5. **Complete the Sentence Screen**
   - Shows the word's example sentence with the target word blanked out (`_____`),
     plus the English translation as a hint
   - 4 multiple-choice Spanish words (correct + 3 same-part-of-speech distractors)
   - Only drawn from words whose example sentence literally contains the word
     itself (so blanking it out is unambiguous)
   - Immediate feedback, then next question; batch of 20, returns to Home
6. **Thematic Learning Screens** (list + category detail)
   - Category list: one row per category (house, nature, city, travel, food, ...),
     showing "`unlocked / total`" words for that category
   - Category detail: flashcard-style list of that category's currently-unlocked
     words (tap to reveal, then "Got it" / "Still learning" — same mastery
     tracking as the Flashcard screen), plus a "Back to categories" button
   - No fixed batch/session-complete step here — it's a running list, not a quiz

Every screen but Home returns to Home (or, for Thematic, to the category list)
when its session/back action completes — no other navigation exists.

## 5. Data Model

### Word dataset (bundled asset, read-only)
Stored as `app/src/main/assets/words.json` and `assets/conjugations.json`, both
loaded into Room on first launch only. Generated by `tools/generate_words.py` (run
manually — see that script's docstring — rather than hand-edited; it applies a
rule-based Spanish conjugator so verb forms stay consistent across ~530 verbs).

```json
[
  {
    "id": 1,
    "spanish": "ser",
    "english": "to be",
    "partOfSpeech": "verb",
    "example": "Quiero ser.",
    "category": "general"
  },
  {
    "id": 530,
    "spanish": "casa",
    "english": "house",
    "partOfSpeech": "noun",
    "example": "Veo la casa todos los días.",
    "category": "house"
  }
]
```

Fields:
- `id`: stable integer, 1–1000
- `spanish`: the word
- `english`: primary translation
- `partOfSpeech`: `"noun"` or `"verb"` (keep the tag set minimal — only what's
  needed for quiz distractor logic)
- `example`: one simple example sentence in Spanish
- `category`: thematic bucket used by Thematic Learning (e.g. `"house"`,
  `"nature"`, `"city"`, `"travel"`, `"food"`, `"family"`, `"body"`, `"health"`,
  `"clothing"`, `"work"`, `"school"`, `"time"`, `"weather"`, `"technology"`,
  `"sports"`, `"animals"`, `"colors"`, `"transportation"`, `"communication"`,
  `"emotions"`, or the catch-all `"general"`) — assigned programmatically by
  best-effort topic match, not hand-curated per word

`conjugations.json` (verbs only, keyed by the matching word `id`):
```json
[
  {
    "wordId": 1,
    "present": {"yo": "soy", "tu": "eres", "el": "es", "nosotros": "somos", "vosotros": "sois", "ellos": "son"},
    "preterite": {"yo": "fui", "tu": "fuiste", "el": "fue", "nosotros": "fuimos", "vosotros": "fuisteis", "ellos": "fueron"}
  }
]
```

### Room entities

**WordEntity** (mirrors the JSON, plus per-word learning state)
| column | type | notes |
|---|---|---|
| id | Int (PK) | matches JSON id |
| spanish | String | |
| english | String | |
| partOfSpeech | String | "noun" \| "verb" |
| example | String | |
| category | String | default "general" |
| timesCorrect | Int | default 0 |
| timesIncorrect | Int | default 0 |
| correctStreak | Int | default 0 — consecutive correct answers across flashcards/quiz/conjugation/sentence, resets to 0 on any wrong answer |
| mastered | Boolean | default false — set true once `correctStreak >= 3` |

**ConjugationEntity** (one row per verb, `wordId` → `WordEntity.id`)
| column | type | notes |
|---|---|---|
| wordId | Int (PK) | |
| presentYo/Tu/El/Nosotros/Vosotros/Ellos | String | present tense, six persons |
| preteriteYo/Tu/El/Nosotros/Vosotros/Ellos | String | preterite tense, six persons |

**ThematicProgressEntity** (one row per category, drives the daily word drip)
| column | type | notes |
|---|---|---|
| category | String (PK) | |
| unlockedCount | Int | default 0 — cumulative, only grows |
| lastUnlockDate | String (ISO date) | nullable; the day this category last unlocked new words |

**AppStateEntity** (single-row table for streak tracking)
| column | type | notes |
|---|---|---|
| id | Int (PK) | always 0, single row |
| currentStreak | Int | consecutive days practiced |
| lastPracticeDate | String (ISO date) | used to compute streak on session completion |

### Thematic Learning unlock logic

Checked once per Home-screen visit (`ensureDailyThematicUnlock`, no-ops after the
first check each day): for every category, if `lastUnlockDate != today`, add 3 to
`unlockedCount` (capped at that category's total word count) and set
`lastUnlockDate = today`. The first `unlockedCount` words of a category (ordered by
`id`) are the ones currently visible — so which 3 words unlock next is fixed by
dataset order, not random.

### Streak logic (daily streak only)

On completing any session (flashcard, quiz, conjugation, or sentence completion —
Thematic Learning has no session/batch concept, so it doesn't touch the streak):
1. Get today's date (device local date, ISO format).
2. Compare to `lastPracticeDate`:
   - If `lastPracticeDate == today` → no change (already practiced today).
   - If `lastPracticeDate == yesterday` → `currentStreak += 1`.
   - Otherwise (gap of 2+ days, or first ever session) → `currentStreak = 1`.
3. Update `lastPracticeDate = today`.

This is the only "strike/streak" mechanic in the app — no per-word strikes.

## 6. Progress Tracking

Progress shown on Home screen is derived, not a separate tracked concept:
- **Mastered count**: `COUNT(*) WHERE mastered = true`
- **Total**: 1000 (or however many words are in the dataset)

No charts, no history graphs — a simple "X / 1000 mastered" text plus the streak
counter is sufficient for v1.

## 7. Word Dataset Sourcing

`tools/generate_words.py` builds both `words.json` and `conjugations.json` from
curated word lists embedded in the script (nouns + verbs only, skipping function
words like articles/prepositions). It:
- Assigns each word a category by best-effort topic match (not hand-curated).
- Conjugates every verb (present + preterite) with a rule-based engine — regular
  `-ar/-er/-ir` endings, stem-changing patterns (e:ie, o:ue, e:i, u:ue), an
  irregular-verb override table, `-car/-gar/-zar` and `-guir` spelling changes,
  and reflexive-verb handling — rather than hand-typing ~530 verbs × 2 tenses ×
  6 persons.
- Builds example sentences from a small set of grammatically-safe templates
  (gendered articles for nouns via a suffix heuristic + exceptions list; a
  conjugated "yo" form or the bare infinitive for verbs) instead of one-off
  hand-written sentences for all 1000 entries.
- Caps the noun list at a round-robin per-category trim so the final dataset
  lands on exactly 1000 words without any one category's tail getting cut.

Re-run it (`python3 tools/generate_words.py`) after editing the word lists in the
script; it overwrites both JSON assets and prints a per-category word count.

## 10. Open Questions / Future Ideas (not in scope now)

- Definition of "mastered" threshold (currently: 3 correct in a row, placeholder)
- Whether to eventually add audio pronunciation (would require bundling audio
  assets — deferred, adds complexity)
- Whether to expand beyond nouns/verbs to other parts of speech
- Notifications/reminders (explicitly deferred per Section 2)
- Conjugate Verbs currently covers present + preterite only — other tenses
  (subjunctive, future, imperfect, ...) would mean extending both the conjugator
  in `tools/generate_words.py` and `ConjugationEntity`'s columns
- Thematic category assignment is a best-effort keyword/topic match, not hand
  reviewed — some words may sit in a category they don't fit perfectly
